# Mock email set

Every message in this folder is fictional and safe to display.

Rules for all mock content:

- Fictional sender names, company names, and domains only.
- All links are disabled. Link text is shown as plain text or as a screenshot with
  no working destination.
- No credential entry form is used anywhere in the training.
- No live attachment is included. Attachments are shown as a file name and icon in a
  screenshot.
- Content is never sent through a real mail system. Participants view it inside the
  training module and the assessment forms.

Each message is tagged with the indicator it demonstrates so the analysis can report
accuracy per indicator. Five legitimate messages are included so the false alarm rate
can be measured.
