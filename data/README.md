# Data

No real participant data is committed to this repository at any point.

- `sample/` contains synthetic records used to test the scoring code. The values were
  generated by a script and do not come from any person.
- Real assessment exports are stored outside the repository in an encrypted,
  access-controlled file and are deleted after the final report is submitted.
- `.gitignore` blocks `data/participants/` and any spreadsheet in `data/` so a real
  export cannot be committed by accident.
